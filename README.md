# 3-Channel Capacitive Touch Sensor Module MX3I1

## Overview
The MX3I1 - 3-Channel Capacitive Touch Sensor Module is a compact and reliable board based on the CAP1203. It enables touch-based input using PCB pads, wires, or conductive surfaces and communicates via the I²C interface.

It supports 3 independent touch channels with built-in calibration and environmental drift compensation, ensuring stable performance across varying conditions. The module operates on both 3.3V and 5V systems, making it suitable for ESP32, STM32, Arduino, and other microcontrollers.

## Key Features
- 3 independent capacitive touch input channels
- I²C interface (fixed address: 0x28)
- Operating voltage: 3.3V to 5V
- Built-in automatic calibration and drift compensation
- Configurable sensitivity and touch parameters via registers
- Active-low interrupt output (ALERT, optional use)
- Standard 2.54mm header for easy integration
- Breadboard-friendly and compact

## Applications
- Touch-based buttons and control panels
- Smart home and IoT user interfaces
- Menu navigation and mode selection
- Appliance and device touch controls
- Interactive and educational electronics projects
